# LearnLab — ห้องเรียนออนไลน์ ม.4–ม.6

เว็บไซต์สรุปบทเรียนวิทยาศาสตร์และคณิตศาสตร์ภาษาไทย ออกแบบด้วย HTML, CSS และ JavaScript แบบไม่ต้องติดตั้งระบบหลังบ้าน

## ไฟล์ในโปรเจกต์
- `index.html` หน้าเว็บและโครงสร้างทุกหน้า
- `style.css` ธีมสีชมพูพาสเทล ตัดด้วยลาเวนเดอร์ มิ้นต์ และครีม พร้อม responsive layout
- `data.js` ข้อมูลบทเรียน 12 บท, สูตร 28 รายการ, แบบทดสอบปรนัย 16 ข้อ และธาตุ 118 ธาตุ
- `app.js` ระบบนำทาง ค้นหาบทเรียน หน้ารายละเอียด ตารางธาตุ คลังสูตร แบบทดสอบ และพิมพ์เอกสาร
- `downloads/` โฟลเดอร์สำหรับเก็บเอกสารสรุปเพิ่มเติม

## เปิดดูในเครื่อง
ดับเบิลคลิก `index.html` หรือเปิดด้วย Live Server ใน VS Code

## เผยแพร่ด้วย GitHub Pages
1. เข้า repository `panida-6-6/learnlab`
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ไว้ที่ root ของ branch `main`
3. ไปที่ Settings → Pages
4. ใน Build and deployment เลือก Deploy from a branch
5. เลือก branch `main` และ folder `/ (root)` แล้วกด Save
6. รอ GitHub สร้างเว็บไซต์ แล้วเปิด `https://panida-6-6.github.io/learnlab/`

## เพิ่มบทเรียน
เพิ่ม object ใหม่ใน array `LESSONS` ภายใน `data.js` โดยกำหนด `id`, `subject` (`science` หรือ `math`), `category`, `level`, `title`, `desc`, `time`, `unit`, `goals`, `sections`, `memory`, `summary` และ `mistakes`

## เพิ่มข้อสอบ
เพิ่ม object ใน array `QUESTIONS` โดย `subject` เป็น `science` หรือ `math`, `level` เป็น ม.4/ม.5/ม.6, `lesson` เป็น id ของบท, `opts` มี 4 ตัวเลือก และ `a` เป็น index คำตอบที่ถูก (เริ่มนับจาก 0)

## หมายเหตุด้านเนื้อหา
ชุดนี้เป็นโครงสร้างเว็บไซต์รุ่นแรกที่มีบทเรียนแกนหลักและเครื่องมือพร้อมใช้งาน เนื้อหาครอบคลุมตัวอย่างหัวข้อสำคัญ แต่ยังไม่ใช่คลังเนื้อหาทุกบทตามหลักสูตรฉบับเต็ม และข้อสอบ 16 ข้อเป็นชุดเริ่มต้น ควรเพิ่มเติมแยกตามตัวชี้วัด/สาระการเรียนรู้และตรวจทานกับหนังสือเรียนหรือหลักสูตรสถานศึกษาก่อนใช้เป็นแหล่งอ้างอิงหลัก
