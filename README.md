# LearnLab — ห้องเรียนออนไลน์วิทยาศาสตร์และคณิตศาสตร์ ม.4–ม.6

เว็บไซต์ทบทวนบทเรียนภาษาไทย สร้างด้วย HTML, CSS และ JavaScript แบบ static site สามารถเปิด `index.html` หรือเผยแพร่ด้วย GitHub Pages ได้

## ไฟล์ในโปรเจกต์
- `index.html` โครงสร้างหน้าเว็บ
- `style.css` รูปแบบและการแสดงผล
- `data.js` ข้อมูลบทเรียน ข้อสอบ สูตร ตารางธาตุ วิดีโอ และคำอธิบายภาพรวมเพิ่มเติม
- `app.js` ระบบนำทาง บทเรียน วิดีโอ แบบทดสอบ แฟลชการ์ด เครื่องคำนวณ และการบันทึกความคืบหน้า

## เนื้อหาและฟังก์ชัน
- บทเรียน 48 บท ครอบคลุมวิทยาศาสตร์และคณิตศาสตร์ ม.4–ม.6
- หน้าเนื้อหาแสดงจุดประสงค์การเรียนรู้ คำอธิบายรายหัวข้อ รายการสำคัญ สูตร ตัวอย่าง สรุป จุดที่มักพลาด และส่วน “ทำความเข้าใจบทนี้ก่อน” ที่อธิบายภาพรวมและเชื่อมโยงแนวคิดของแต่ละบท
- คลังวิดีโอ: บทที่มีลิงก์คลิปโดยตรงจะคงลิงก์เดิมไว้ ส่วนบทที่ยังไม่มีคลิปเฉพาะจะแสดงลิงก์ค้นหาชื่อบทบน YouTube แทนการปล่อยให้ไม่มีทางไปต่อ
- แฟลชการ์ดสร้างจากคำอธิบาย นิยาม หลักการ ตัวแปร สถานการณ์ ตัวอย่าง สูตร และสรุป พร้อมตัวกรองวิชา ระดับ และบทเรียน รวมถึงปุ่มพลิกบัตร ก่อนหน้า และถัดไป
- แบบทดสอบมีชุดก่อนเรียนและหลังเรียน บทละ 20 ข้อ พร้อมเฉลยและคำอธิบาย
- เครื่องคำนวณเบื้องต้น 4 แบบ: อัตราเร็วเฉลี่ย กฎข้อที่ 2 ของนิวตัน จำนวนโมลจากมวล และความเข้มข้นโมลาร์
- ตารางธาตุ 118 ธาตุ คลังสูตร และระบบพิมพ์/บันทึกบทเรียนเป็น PDF

## วิดีโอ YouTube
มีบทเรียน 28 จาก 48 บทที่มีลิงก์ไปยังคลิปโดยตรงอยู่แล้ว โดยคง URL เดิมไว้ ส่วนอีก 20 บทจะแสดงลิงก์ผลการค้นหา YouTube ตามชื่อบท ระดับชั้น และภาษาไทย เพื่อให้เลือกคลิปที่ตรงกับบทเรียนได้เอง ลิงก์ค้นหาไม่ใช่การรับรองคุณภาพของคลิปที่แสดงในผลลัพธ์

## แฟลชการ์ด
แฟลชการ์ดไม่ใช้ชื่อหัวข้อเป็นคำถามอย่างเดียว แต่ดึงเนื้อหาจากคำอธิบายและรายการสำคัญมาสร้างคำถาม เช่น ความหมายของคำศัพท์ หน้าที่ขององค์ประกอบ สาเหตุและผล สัญลักษณ์ที่ใช้ในสูตร และการอธิบายสถานการณ์ เมื่อพลิกบัตรจะแสดงแนวคำตอบจากเนื้อหาบทเรียน

## เผยแพร่ด้วย GitHub Pages
1. แตกไฟล์ ZIP
2. นำไฟล์ทั้งหมดในโฟลเดอร์นี้ไปแทนที่ไฟล์เดิมใน root ของ repository
3. Commit changes และรอ GitHub Pages เผยแพร่

## ข้อจำกัดที่ควรทราบ
- เนื้อหาเป็นสื่อทบทวน ไม่ใช่เอกสารหลักสูตรหรือข้อสอบทางการ ควรเทียบกับหนังสือเรียนและแนวทางของโรงเรียน
- แบบทดสอบเป็นแบบฝึกหัดเพื่อทบทวน พร้อมคำอธิบาย ไม่ใช่คลังข้อสอบที่ผ่านการรับรองจากหน่วยงานสอบ
- ลิงก์ YouTube อาจเปลี่ยนแปลงได้ และผลการค้นหาขึ้นกับ YouTube
- ความคืบหน้าและรีวิวถูกเก็บในเบราว์เซอร์ของผู้ใช้แต่ละคน ไม่ได้รวมเป็นฐานข้อมูลกลาง
